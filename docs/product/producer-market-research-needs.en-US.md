# Producer Market Research Needs

## Research stage

Comparable Games supports early product research: building and refining candidate comparables before deeper commercial and production analysis.

## Core questions

- Which games share relevant genre, subgenre, platform, period, mode, perspective, theme, audience, or business-model traits?
- Which developers and publishers operate in the same space?
- Is a result a direct, aspirational, gameplay, visual, audience, or adjacent reference?
- Which information is official, curated, aggregated, estimated, community-maintained, conflicting, or outdated?
- Which original source should be inspected next?
- How much coverage is lost under stricter confidence requirements?

## Needs

| Need | Required data | MVP priority |
|---|---|---|
| Discover candidates | Name, genre, platform, release period | Essential |
| Refine relevance | Subgenre, tags, themes, modes, perspective | High |
| Identify companies | Developer and publisher | High |
| Understand releases | Platform, region, date, status | High |
| Evaluate trust | Source, nature, confidence, verification | Essential |
| Continue research | Verified original URL | Essential |
| Control breadth | Reliability classification | High |
| Compare selected games | Structured cross-game view | Later |
| Evaluate performance | Sales-first metrics and contextual observations | Future |

## Pain points

- fragmented sources and many tabs;
- dependence on exact search terms;
- weak comparability based only on broad genres;
- manual spreadsheets and conflict reconciliation;
- unclear reliability and freshness;
- searches that are difficult to reproduce.

## Product response

Use structured filters, normalized records, preserved provenance, visible reliability, verified source links, shareable URLs, progressive disclosure, and explicit candidate-comparable language.

Before adding a field, ask which producer decision it supports, whether it is reliable and authorized, and whether it belongs in the MVP.

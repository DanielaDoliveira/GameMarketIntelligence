# Product Value Proposition

## Purpose

Game Market Intelligence is a free, non-commercial decision-support application for game producers conducting early market research.

## Problem

Research is fragmented across search engines, stores, databases, official pages, industry tools, spreadsheets, and notes. Results often lack comparable context, provenance, freshness, and a clear distinction between official facts, curation, community data, and estimates.

## Value proposition

> GMI organizes comparable-game information from clearly identified sources in one structured and reliability-aware environment, reducing fragmented browsing and manual reconciliation while preserving provenance, limitations, and links for continued research.

## Target users

- game producers;
- technical producers;
- indie developers acting as producers;
- small-studio founders;
- product, publishing, and market-research teams.

## MVP value

1. Comparable Games with basic and progressively disclosed advanced filters.
2. Data Sources with coverage, reliability, restrictions, attribution, and original links.
3. Reliability modes that make the confidence-versus-coverage trade-off explicit.

## Boundaries

GMI does not:

- replace producer judgment or original sources;
- declare every result a direct competitor;
- reproduce complete upstream databases;
- present estimates as official facts;
- infer sales from reviews, rankings, or concurrent players;
- promise complete market coverage.

## Core rule

GMI only presents data it can justify, trace, and use with authorization. Missing reliable data is preferable to doubtful data.

# External Source Evaluation Rules

## Purpose

Define the mandatory process used whenever GMI evaluates a new external source.

## Evaluation order

1. Producer question served.
2. Reliability by data category.
3. Professional usefulness.
4. Legal permission and zero-cost eligibility.
5. Coverage and marginal value.
6. Technical integration.

Legal permission and mandatory cost are eliminatory.

## Required evidence

For each source, record:

- owner and official/independent status;
- supplied data categories;
- source, curation, or estimation methodology;
- storage, caching, display, redistribution, and attribution rules;
- image and description restrictions;
- authentication, limits, pagination, updates, and stable IDs;
- expected normalization and reconciliation effort;
- risk of source lock-in or future cost;
- decision and reconsideration condition.

## Reliability model

Reliability belongs to a value or category, not blindly to a website.

Use clear data natures such as:

- official;
- primary;
- curated;
- aggregated;
- community-maintained;
- estimated;
- inferred;
- reconciled;
- conflicting;
- unverified.

## Decision outcomes

- selected as primary general source;
- selected for reconciliation or enrichment;
- selected as official specialized source;
- validation/reference only;
- not selected;
- reconsider later under explicit conditions.

## Governance rule

Technical accessibility is never treated as authorization. Public visibility, robots.txt, sitemaps, JSON-LD, or undocumented endpoints do not by themselves permit automated reuse.
